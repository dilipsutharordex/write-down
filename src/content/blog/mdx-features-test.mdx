# Welcome to MDX Testing

This post demonstrates the powerful features of MDX, combining Markdown's simplicity with JSX's flexibility.

## What Makes MDX Special?

MDX allows you to:
- Write **Markdown** content naturally
- Embed **React/JSX components** directly
- Use JavaScript expressions inline
- Create interactive documentation

## Code Examples

MDX supports all standard Markdown features, including syntax-highlighted code blocks:

```javascript
// JavaScript example
const greeting = (name) => {
  return `Hello, ${name}! Welcome to MDX.`;
};

console.log(greeting('Developer'));
```
